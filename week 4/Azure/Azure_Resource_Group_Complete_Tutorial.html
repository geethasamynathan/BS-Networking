1. What is an Azure Resource Group?

An Azure Resource Group (RG) is a logical container for related Azure resources—such as virtual machines, storage accounts, virtual networks, network security groups, and public IP addresses.

Think of a Resource Group as a project folder. The resources in it are real cloud services, but the Resource Group helps you organize, secure, track, deploy, and remove them as a unit. A Resource Group is not itself a network or a physical machine.

Teaching point: Resource Groups let you manage a solution together, but they do not automatically make every resource communicate with every other resource.

4. Why Do Companies Use Resource Groups?

📁 Organization

Keep resources for a project or environment discoverable in one place.

🔐 Access control

Apply Azure RBAC roles to an RG; permissions generally inherit to resources beneath it.

💰 Cost analysis

Filter and analyze costs associated with resources in a group; the RG itself has no usage charge.

🚀 Deployment

Use ARM or Bicep templates to consistently deploy related infrastructure.

🏷 Governance

Use Azure Policy, tags, and management conventions for organization.

🧹 Cleanup

Delete the RG to remove its contained resources when the lab is no longer needed.

Important: Deleting an RG is a destructive action. It can remove VMs, disks, storage accounts, and data. Review its contents before deleting.

5. Resource Group Region vs. Resource Region

The RG's selected location stores management metadata for the group. Its resources can be located in a different supported Azure region.

ItemLocation
Resource GroupCentral India
VM 1Central India
VM 2South India
Choose the VM's own location based on latency, compliance, availability and service support. Moving a resource into another RG does not physically relocate it to the RG's region.

6. Hands-on Lab — Create a Resource Group (Azure Portal Only)

Lab objective: Create CompanyABC-Training-RG in Central India, locate it, and understand the empty resource list.

Prerequisites: An Azure account, an accessible subscription, and permission to create resource groups (for example, sufficient Contributor access at subscription scope).

1

Sign in to Azure Portal

Open https://portal.azure.com and sign in using the account with access to your training subscription.

2

Search for Resource groups

In the search bar at the top, enter Resource groups. Select the Resource groups service from the search results.

3

Choose Create

On the Resource groups page, select + Create to open the creation wizard.

4

Complete the Basics tab

Use the example values below (your actual subscription name may differ).

FieldValueMeaning
SubscriptionYour training subscriptionWhere the RG will be created
Resource groupCompanyABC-Training-RGName of the logical container
RegionCentral IndiaLocation of the RG metadata
5

Optional Tags tab

For a training example, you can add Environment = Training and Project = CompanyABC. Tags are useful for organization; tags assigned to an RG do not automatically propagate to all its resources.

6

Review and create

Select Review + create. After validation succeeds, select Create.

7

Verify the new Resource Group

Go to Resource groups, search CompanyABC-Training-RG, and open it. Confirm the subscription, location and tags. The Resources list will initially be empty.

Expected result: Your empty Resource Group exists and is ready for resources. Simply creating it does not deploy a VM or other chargeable resource.

7. What Can You Do After Creating It?

Add a resource

  1. Go to Create a resource in Azure Portal.
  2. Choose the desired service, such as Virtual Machine or Virtual Network.
  3. During configuration, select CompanyABC-Training-RG as the Resource Group.
  4. Review and deploy the resource.

Check resources and costs

Open the Resource Group to browse its resources. For cost analysis, use Cost Management + Billing / Cost Management → Cost analysis where permitted, and filter by the Resource Group. Visibility depends on subscription billing and RBAC roles.

Manage access (RBAC)

Open the Resource Group → Access control (IAM) → Add role assignment. Assign the least-privilege role required (e.g., Reader for read-only access). You must have sufficient permission to assign roles.

Delete the Resource Group — only for an empty lab or approved cleanup

  1. Open CompanyABC-Training-RG.
  2. Review the Resources list carefully and verify nothing important remains.
  3. Select Delete resource group.
  4. Complete the portal's confirmation steps.
Warning: Deleting a Resource Group triggers deletion of contained resources; some services have separate recovery rules, but do not assume data can be restored. Consider a deletion lock and backups for production resources.

Can you move a resource to a different RG?

Some Azure resources support moves across Resource Groups, subject to dependencies and restrictions. A move changes management grouping—not the resource's deployment region.

8. Recap Questions & Answers

Q1. Is an Azure Resource Group chargeable?

No charge for the Resource Group container itself. Individual resources running within it can incur charges.

Q2. Can one resource belong to two Resource Groups at once?

No. A given Azure resource belongs to one Resource Group at a time.

Q3. Does the Resource Group's region force the VM to use that region?

No. The RG location specifies its management metadata location. VM location is chosen separately.

Q4. Does a Resource Group provide network isolation?

No. Use Azure networking controls such as VNets, NSGs, Azure Firewall, and private endpoints as appropriate.

Q5. If you delete a Resource Group, what happens?

Azure attempts to delete all its contained resources. Treat the operation as destructive and perform cleanup only with authorization.

Q6. Why create separate RGs for development and production?

Separating resources based on lifecycle, ownership, permissions, and governance makes managing and protecting production easier.

Q7. Can you assign one RBAC role to a whole RG?

Yes. RBAC assignments at the Resource Group scope are inherited by resources within that scope, subject to Azure authorization behavior.

Q8. What is the best first step before an Azure VM training lab?

Create a dedicated training Resource Group to keep demo infrastructure easy to find and clean up afterward.
