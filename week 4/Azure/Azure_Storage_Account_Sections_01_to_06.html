01 · Foundations and real-world scenario

CompanyABC runs an e-commerce application. It must store product images, invoices, HR documents, order-processing requests, order status, VM data and analytical datasets. Traditional local servers require hardware, capacity planning and maintenance. Azure Storage provides managed cloud storage, with configurable redundancy, access control and monitoring.

What is a storage account?

A storage account is an Azure resource and management boundary for data services. A standard general-purpose v2 (StorageV2) account supports blobs, files, queues and tables. Managed disks are separate Azure resources; ADLS Gen2 adds hierarchical namespace capabilities to Blob Storage.

Lab 13 — Understand asynchronous processing
Customer places order
↓
Application submits message
Queue stores work
Worker retrieves and processes
↓

Queues decouple order submission from background work. They do not execute application code. Design workers to handle retries and duplicate delivery.

Lab 14 — Create queue and add messages
  1. Storage account → Queues → + Queue.
  2. Name: order-processing → Create.
  3. Open queue → Add message → paste sample JSON.
  4. Set expiry and encoding as appropriate; submit.
  5. Repeat with ORD1002. Inspect messages using portal or Storage Explorer.
  6. Use a worker or authorized CLI to retrieve, process and delete messages.
{"OrderId":"ORD1001","CustomerId":"CUST101","Amount":2500,"Status":"Pending"}
Retrieval temporarily hides a message; successful processing should be followed by deletion using its message ID and pop receipt.

PartitionKey + RowKey is a point query, the most efficient individual entity lookup. PartitionKey filters narrow the scan; other properties are not automatically indexed. Numeric comparisons require numeric Amount values. Results above include all five sample entities.
