SECTION 01

What is Linux?

Linux is an open-source operating system kernel. Complete Linux distributions combine the kernel, utilities, libraries, and optionally a graphical desktop.

Linux is used in cloud servers, websites, databases, containers, software development, network infrastructure, automation and embedded devices.

Real-world scenario: A customer opens an online shopping website. The request travels to a Linux-based web/application server, which reads product data from a database and returns a response. Linux manages processes, files, memory, hardware and network connections.

Connecting to Linux

You can connect through Windows Subsystem for Linux (WSL), a virtual machine, an SSH connection to a remote server, a cloud console, or a physical Linux computer.

Windows 11 PC
PowerShell / Terminal / VS Code
WSLUbuntu on same PC
SSHLAN / remote Linux server
VM ConsoleVirtualBox / Hyper-V
CloudAzure / AWS Linux VM

Method 1 — Ubuntu with WSL on Windows

  1. Open PowerShell as Administrator.
  2. wsl --install -d Ubuntu
  3. Restart the computer if requested, launch Ubuntu, and create the Linux username and password.
  4. wsl -d Ubuntu
  5. Verify Linux and the current location:
  6. uname -s
pwd
# Example:
Linux
/home/geetha

Method 2 — SSH remote server

Windows SSH client
↓
Encrypted SSH connection (usually TCP 22)
↓
Linux SSH server (sshd)
  1. On Ubuntu server, install and start the SSH service:
  2. sudo apt update
sudo apt install openssh-server
sudo systemctl enable --now ssh
  3. Find a server IP address:
  4. hostname -I
# Example: 192.168.1.100
  5. Connect from Windows PowerShell:
  6. ssh geetha@192.168.1.100
  7. Verify the host fingerprint, authenticate and work at the remote shell prompt:
  8. geetha@ubuntu-server:~$

Requirement: The server must be reachable, SSH running, and firewall rules must allow permitted connections.

Method 3 — Virtual machine

Method 4 — Cloud VM

ssh -i ~/.ssh/cloud_key azureuser@203.0.113.10

SECTION 09

Essential File and Directory Commands

pwd — Working Directory

Shows absolute path of current location.

pwd
# /home/geetha

ls — List Contents

Shows files and directories. Options include -l, -a, -lh, -la, -lt.

ls
ls -l
ls -a
ls -lh
# Sample: data  demo  documents  projects

cd — Change Directory

Move to a directory, parent, home or previous directory.

cd /home/geetha
cd demo
cd ..
cd ~
cd -

mkdir — Create Directory

Creates one folder or nested folders using -p.

mkdir linuxlab
mkdir -p projects/linux/scripts

touch — Create File

Create an empty file or update timestamps.

touch sample.txt
touch file1.txt file2.txt file3.txt

cat — Display File

Write and view text files. > overwrites and >> appends.

echo "Linux is powerful" > sample.txt
echo "Linux is open-source" >> sample.txt
echo "Linux runs on servers" >> sample.txt
cat sample.txt
# Linux is powerful
# Linux is open-source
# Linux runs on servers

cp — Copy

Copy files or directories (-r).

cp sample.txt backup.txt
cp -r projects projects_backup

mv — Move / Rename

Rename a file or move it to another location.

mv sample.txt linuxnotes.txt
mkdir -p documents
mv linuxnotes.txt documents/

rm and rmdir — Remove

Remove files and empty folders; -r removes directory trees. Check carefully.

rm unwanted.txt
rmdir emptyfolder
rm -r oldproject

clear — Clear Screen

Clear terminal visible display.

clear
Warning: rm usually deletes immediately rather than using a graphical Recycle Bin; check all paths carefully.
SECTION 10

Reading Files and Searching Text

Create the sample employee file:

cat > employees.txt <<'EOF'
101,Arun,Developer
102,Meena,Tester
103,Ravi,Developer
104,Priya,Administrator
105,Kumar,Developer
EOF

head

Display first lines. Defaults to 10.

head -n 3 employees.txt
# 101,Arun,Developer
# 102,Meena,Tester
# 103,Ravi,Developer

tail

Display last lines; -f follows appended log data.

tail -n 2 employees.txt
# 104,Priya,Administrator
# 105,Kumar,Developer
tail -f application.log

grep

Search text. -i ignore case, -n show line numbers, -c count, -v invert, -r recursive.

grep "Developer" employees.txt
# 101,Arun,Developer
# 103,Ravi,Developer
# 105,Kumar,Developer
grep -in "developer" employees.txt
grep -c "Developer" employees.txt

wc

Count lines, words and bytes.

wc -l employees.txt
# 5 employees.txt
wc -w employees.txt
wc -c employees.txt

sort and uniq

Sort and remove adjacent duplicates; use both together for all duplicates.

sort names.txt | uniq

Pipe: | sends one command’s standard output to the next command’s standard input.

LetterPermissionValue

wWrite2

chmod 755 script.sh
sudo chown geetha:geetha script.sh

With 755, the owner has read+write+execute (7), and group and others have read+execute (5). sudo executes an authorized command with elevated privileges.

SECTION 13

Processes and Services

A process is a running program. A service is often a background program managed by the operating system.

ps aux
ps aux | grep nginx
top
# Press q to exit top

On Ubuntu using systemd, manage the Nginx service (when installed):

sudo systemctl start nginx
sudo systemctl stop nginx
sudo systemctl restart nginx
sudo systemctl status nginx
sudo journalctl -u nginx -n 20

Example status: Active: active (running).

SECTION 18

Practical Lab — Shell Script Backup

Scenario: Automate backup of the employee file.

  1. Create a script:
  2. nano backup.sh
  3. Enter this Bash script:
  4. #!/bin/bash
set -e
echo "Starting Employee Backup"
mkdir -p "$HOME/company/backup"
cp "$HOME/company/employees/staff.txt" \n   "$HOME/company/backup/staff_backup.txt"
echo "Backup Completed Successfully"
ls -lh "$HOME/company/backup/staff_backup.txt"
  5. Save using Ctrl+O, Enter, Ctrl+X. Make executable:
  6. chmod +x backup.sh
  7. Run:
  8. ./backup.sh
# Starting Employee Backup
# Backup Completed Successfully
# -rw-r--r-- 1 geetha geetha 99 Oct 28 09:15 /home/geetha/company/backup/staff_backup.txt

#!/bin/bashExecute with Bash
set -eExit on many command failures; with Bash exceptions
echoPrint text
mkdir -pCreate target folder as needed
cpCopy data
$HOMEUser home directory
ls -lhShow detailed file information

↓
Bash interprets commands
↓

↓
Write backup/staff_backup.txt
↓
Display backup result
