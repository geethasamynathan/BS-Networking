Linux Commands – Disk Usage and Process Management

These commands work in Ubuntu Linux / WSL. We will cover disk monitoring first, followed by process monitoring and management, with commands, sample outputs, and explanations.

Part 1: Disk Usage Commands

1. df -h – Check disk space

df -h

Example output:

Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1       100G   45G   55G  45% /
tmpfs           3.9G   20M  3.8G   1% /run

Explanation:

  • Size – Total filesystem size
  • Used – Used disk space
  • Avail – Available disk space
  • Use% – Percentage used
  • Mounted on – Filesystem mount point

-h means human-readable format (KB, MB, GB).

2. du -sh – Check directory size

du -sh /home/geetha

Example output:

2.5G    /home/geetha

Check the current directory:

du -sh .

Check individual directories:

du -sh *

Example output:

120M    projects
50M     backups
10M     reports

3. Find the largest directories

du -h --max-depth=1 ~ | sort -hr

Example output:

2.5G    /home/geetha
1.5G    /home/geetha/projects
600M    /home/geetha/backups
200M    /home/geetha/reports

Useful when a server is running out of disk space.

4. lsblk – Display disk and partition information

lsblk

Example output:

NAME   MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sda      8:0    0  100G  0 disk
└─sda1   8:1    0  100G  0 part /

For filesystem details:

lsblk -f

5. df -i – Check inode usage

df -i

Useful when Linux reports no space left even though the filesystem still has free storage.

Part 2: Linux Process Management

A process is a running instance of a program.

For example, when you execute sleep 100, Linux creates a process that waits for 100 seconds.

How a Linux process works
User executes command
sleep 100
↓
Linux creates process
Assigns a PID
↓
Process runs
Uses memory and CPU as needed
↓
Process terminates
Resources are released

Important Process Commands

1. ps – Display processes

ps

Example output:

PID   TTY       TIME CMD
1201  pts/0 00:00:00 bash
1302  pts/0 00:00:00 ps

Display all processes:

ps -ef

Display detailed process information:

ps aux

2. top – Monitor processes in real time

top

Shows:

  • CPU utilization
  • Memory utilization
  • Running processes
  • Process IDs
  • Process state

Press q to exit.

Sort by CPU consumption inside top: Press P.

Sort by memory consumption: Press M.

3. htop – Interactive process monitoring

Install:

sudo apt update
sudo apt install htop

Execute:

htop

This provides a more interactive process monitoring interface. Press q to exit.

4. sleep – Create a sample process

Run:

sleep 300

This creates a process that waits for 300 seconds.

To run it in the background:

sleep 300 &

Example output:

[1] 2456

Here 2456 is the process ID (PID).

5. jobs – Display background jobs

jobs

Example:

[1]+ Running sleep 300 &

Bring the job to the foreground:

fg %1

Stop the foreground job temporarily using Ctrl + Z.

Resume it in the background:

bg %1

6. pgrep – Find process IDs

pgrep sleep

Example output:

2456

To display the command name:

pgrep -a sleep

7. kill – Terminate a process

kill 2456

This sends the default SIGTERM signal, asking the process to terminate.

Forcefully kill if normal termination fails:

kill -9 2456

Use kill -9 only when necessary because the process cannot handle the signal or perform normal cleanup.

8. pkill – Terminate processes by name

pkill sleep

This terminates matching processes.

9. free -h – Monitor memory usage

free -h

Example output:

               total  used  free shared buff/cache available
Mem:            16Gi  4Gi   8Gi   200Mi       4Gi      11Gi
Swap:            4Gi  0Gi   4Gi

This checks RAM and swap, not disk storage.

10. uptime – Check system uptime and load

uptime

Example output:

21:30:00 up 2 days, 3:20, 2 users, load average: 0.25, 0.40, 0.35

Load averages represent approximately the last 1, 5, and 15 minutes of system load.

Part 3: Hands-on Industry Scenario – Linux Server Monitoring

Scenario: You are a Linux administrator. Your application server is becoming slow. You need to determine whether the problem involves disk space, memory, or CPU usage.

Execute these commands in order.

StepCommandPurpose
1df -hCheck disk space
2du -sh /var/logCheck log directory size
3du -sh *Check sizes of current directory contents
4free -hCheck RAM usage
5topMonitor CPU and processes
6ps aux --sort=-%cpu | headFind CPU-consuming processes
7ps aux --sort=-%mem | headFind memory-consuming processes
8pgrep -a pythonFind Python processes
9uptimeCheck server uptime and load
10kill PIDTerminate a selected process safely

Part 4: Practical Process Lab

Try this in your Ubuntu terminal.

Step 1. Create three background processes.

sleep 600 &
sleep 700 &
sleep 800 &

Step 2. Display background jobs.

jobs -l

Step 3. Find process details.

pgrep -a sleep

Step 4. Monitor processes.

top

Press q to exit.

Step 5. Terminate a specific process.

kill <PID>

Replace <PID> with the actual process ID returned in Step 3.

Step 6. Verify.

pgrep -a sleep

Step 7. Terminate remaining sleep processes.

pkill -x sleep

Step 8. Verify all processes have stopped.

jobs -l
pgrep -a sleep

If pgrep returns no output, no matching running process was found.

Important distinction: df and du monitor disk usage, free monitors RAM usage, and ps/top monitor running processes.

For your next Linux administration practice, the natural continuation is services management using systemctl, process priority using nice and renice, and application monitoring using journalctl and nohup. These connect process management to real production server operations.
