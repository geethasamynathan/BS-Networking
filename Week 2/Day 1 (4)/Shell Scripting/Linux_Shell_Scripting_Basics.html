1. What is shell scripting?

A shell is a command interpreter that accepts commands and communicates with the operating system. A shell script is a text file containing multiple shell commands that can be executed together to automate tasks.

Why do companies use shell scripting?

Imagine an e-commerce company managing a Linux server. Every day, an administrator must check disk space, verify services, archive log files, and generate reports. Instead of typing these commands manually, a shell script performs them automatically.

3. Your first shell script

Step 1 — Create the file

BASH
nano hello.sh

Type the following code in Nano:

BASH
#!/bin/bash

echo "Welcome to Linux Shell Scripting"
echo "This is my first Bash program"
date
whoami
pwd

Step 2 — Save the file

  1. Press Ctrl + O to write the file.
  2. Press Enter to confirm the filename.
  3. Press Ctrl + X to exit Nano.

BASH

4. Different ways to execute shell scripts

Assume your script is named hello.sh.

MethodCommandExplanation
Bash interpreterbash hello.shRuns using Bash; execute permission is not required on the script.
Shell interpretersh hello.shRuns with sh; Bash-specific features may fail.
Direct execution./hello.shRequires executable permission and a valid interpreter.
Absolute path/home/geetha/shell-training/hello.shRuns from any directory when permission is granted.
Sourcesource hello.shRuns in the current shell.
Dot command. ./hello.shEquivalent to source for this use.
Background./hello.sh &Starts the script in the background.

Make the file executable

BASH
chmod +x hello.sh
./hello.sh

Inspect permissions

BASH
ls -l hello.sh
OUTPUT
-rwxr-xr-x 1 geetha geetha 125 Nov 5 hello.sh

The x permission indicates executable access.

Key distinction: bash hello.sh launches a new shell process. source hello.sh executes in your current shell, so variable assignments and directory changes can affect the terminal session.

5. Variables in shell scripting

A variable stores a value, such as an employee name, server, directory, or number.

Create a script using nano variables.sh:

BASH
#!/bin/bash

company="TechNova"
employee="Ravi"
salary=45000

echo "Company: $company"
echo "Employee: $employee"
echo "Salary: $salary"

echo "Home directory: $HOME"
echo "Current user: $USER"

Execute

BASH
bash variables.sh

Example output

OUTPUT
Company: TechNova
Employee: Ravi
Salary: 45000
Home directory: /home/geetha
Current user: geetha

Variable assignment rules

BASH
name="Ravi"       # Correct
name = "Ravi"     # Incorrect

Bash variable assignment does not permit spaces around =. Use quoted expansions such as "$company" when working with paths or strings.

Read-only variables

BASH
readonly company="TechNova"

Environment variables

BASH
export APP_ENV="production"

Exported variables are inherited by child processes.

6. Accept user input

Use the read command to collect values from a user. Create input.sh:

BASH
#!/bin/bash

read -r -p "Enter employee name: " name
read -r -p "Enter department: " department

echo "Employee: $name"
echo "Department: $department"

Run

BASH
bash input.sh

Example output

OUTPUT
Enter employee name: Ravi
Enter department: IT
Employee: Ravi
Department: IT

read accepts user input, -p shows a prompt, and -r prevents backslash escapes from being processed.

7. Arithmetic operations

Use $((...)) for integer calculations in Bash. Create arithmetic.sh:

BASH
#!/bin/bash

a=20
b=5

echo "Addition: $((a+b))"
echo "Subtraction: $((a-b))"
echo "Multiplication: $((a*b))"
echo "Division: $((a/b))"
echo "Remainder: $((a%b))"

Output

OUTPUT
Addition: 25
Subtraction: 15
Multiplication: 100
Division: 4
Remainder: 0
Bash arithmetic uses integers by default: 7 / 2 gives 3.

8. Conditions — if, else, elif

Conditional statements let your script decide what action to take. Example: an alert based on a disk-usage percentage entered by a user.

Create disk-check.sh:

BASH
#!/bin/bash

read -r -p "Enter disk usage percentage: " usage

if ! [[ "$usage" =~ ^[0-9]+$ ]] || (( usage > 100 )); then
    echo "Invalid percentage"
    exit 1
fi

if (( usage >= 90 )); then
    echo "CRITICAL: Disk usage is high"
elif (( usage >= 75 )); then
    echo "WARNING: Disk usage is increasing"
else
    echo "NORMAL: Disk usage is healthy"
fi

Execute

BASH
bash disk-check.sh

Example output

OUTPUT
Enter disk usage percentage: 92
CRITICAL: Disk usage is high

Useful conditional operators

-ltLess than
-geGreater than or equal

-xExecute permission exists

9. File and directory conditions

Check whether configuration files exist before processing them. Create file-check.sh:

BASH
#!/bin/bash

file="/etc/hosts"

if [[ -f "$file" ]]; then
    echo "File exists"
    echo "File content:"
    cat "$file"
else
    echo "File not found"
fi

Run with bash file-check.sh. The -f test checks for a regular file; -d tests for a directory.

10. Case statements

Use a case statement when users choose from a fixed menu. Create menu.sh:

BASH
#!/bin/bash

echo "1. Show date"
echo "2. Show current user"
echo "3. Show disk usage"
echo "4. Exit"

read -r -p "Choose an option: " choice

case "$choice" in
    1) date ;;
    2) whoami ;;
    3) df -h ;;
    4) echo "Goodbye" ;;
    *) echo "Invalid option" ;;
esac

The *) branch handles any input that does not match options 1–4. Execute with bash menu.sh.

11. Looping in Bash

Loops repeat a block of commands. The three common forms are for, while, and until.

Start loop
↓
Condition?
True ↓False → Stop
Execute commands
↺ Repeat

11.1 For loop

Create for-loop.sh:

BASH
#!/bin/bash

for number in 1 2 3 4 5
do
    echo "Processing task $number"
done
OUTPUT
Processing task 1
Processing task 2
Processing task 3
Processing task 4
Processing task 5

11.2 C-style for loop

BASH
for ((i=1; i<=5; i++))
do
    echo "Iteration $i"
done

11.3 While loop

Create while-loop.sh:

BASH
#!/bin/bash

count=1

while (( count <= 5 ))
do
    echo "Count: $count"
    ((count+=1))
done

11.4 Until loop

BASH
count=1

until (( count > 5 ))
do
    echo "Count: $count"
    ((count+=1))
done

A while loop runs while its condition is true; an until loop runs while its condition is false.

11.5 Break and continue

BASH
for ((i=1; i<=10; i++))
do
    if (( i == 3 )); then
        continue
    fi

    if (( i == 8 )); then
        break
    fi

    echo "$i"
done
OUTPUT
1
2
4
5
6
7

continue skips the current iteration. break exits the loop.

12. Arrays

Bash indexed arrays store multiple values under a single name. Create arrays.sh:

BASH
#!/bin/bash

servers=("web01" "db01" "app01")

echo "First server: ${servers[0]}"
echo "Number of servers: ${#servers[@]}"

for server in "${servers[@]}"
do
    echo "Checking $server"
done

Output

OUTPUT
First server: web01
Number of servers: 3
Checking web01
Checking db01
Checking app01
ExpressionMeaning
${servers[0]}First array item (index 0)
${#servers[@]}Number of array items
"${servers[@]}"All array items, with each item kept separate

13. Functions

A function groups reusable commands. Create functions.sh:

BASH
#!/bin/bash

greet() {
    echo "Welcome, $1"
}

add() {
    local result=$(( $1 + $2 ))
    echo "$result"
}

greet "Ravi"

total=$(add 20 30)
echo "Total: $total"

Output

OUTPUT
Welcome, Ravi
Total: 50

$1 and $2 are function arguments. local limits a variable to the function. $(add 20 30) captures what the function prints.

Important: Bash return provides a numeric exit status, not a general-purpose value. To produce text or a computed result, a function can print it using echo and the caller can capture that output.

14. Command-line arguments

Scripts can accept arguments passed directly on the command line. Create arguments.sh:

BASH
#!/bin/bash

echo "Script name: $0"
echo "First argument: ${1:-not supplied}"
echo "Second argument: ${2:-not supplied}"
echo "Total arguments: $#"

echo "All arguments:"
printf '%s\n' "$@"

Execute

BASH
bash arguments.sh Ravi IT

Output

OUTPUT
Script name: arguments.sh
First argument: Ravi
Second argument: IT
Total arguments: 2
All arguments:
Ravi
IT
ParameterMeaning
$0Name/path used to invoke the script
$1, $2First and second positional arguments
$#Number of positional arguments
"$@"All arguments, preserving each argument boundary
$?Status of the previously executed command
$$Process ID of the current shell

The expression ${1:-not supplied} uses the fallback text when the first argument is unset or empty.
